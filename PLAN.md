## Global constraints (every task)

1. **Content rule:** text only from `01-scan/content/*.json` (verbatim), `03-copy/approved.json` (an approved rewrite replaces the block whose text equals its `original`), or `06-build/functional-text.json`. Gaps are the literal `[דרוש תוכן: …]`. No couple names anywhere (text, alt, file name, URL, caption); `panneau-bienvenue-mariage.jpg` never used. Never type copy into a component: read it through `t()` / `ft()` (T04, T06).
2. **Static only:** no API routes, no server, no BaaS, no new third party. Only GA4 `G-4VN4372P6E` behind consent (default denied), the client's for-system planner on its 8 pages, external links (Zenchef, Matterport, mariages.net, Pinterest, Calameo, Google review/Maps, Instagram, Facebook). Fairguest, AddToAny, `wp-tours.js`, IconCaptcha, search, poll: not shipped.
3. **Tokens only** (policy/design-tokens.md): every colour, size, space, radius, duration and easing is a `var(--…)` from tokens.css. A missing value → stop, list it in OPEN; the orchestrator updates DESIGN.md and T02 emits again. `--frame: none`: no borders/outlines/rings/shadows on content or photos (the field underline `--border-field` and focus rings are the only lines). Nine colours only; no scrim.
4. **Mobile** (policy/mobile.md, DESIGN §14): hover only inside `@media (hover: hover) and (pointer: fine)`; `:active` press states; targets ≥ `--tap-min`; `100svh` with `100vh` fallback; inputs `--fs-field` (≥16 px); no `user-scalable=no`; no horizontal overflow at 320/390.
5. **Motion level 3** (§6): CSS + small vanilla JS, `requestAnimationFrame`, time-based easing, passive listeners. Every moving thing has its quiet version under `prefers-reduced-motion: reduce` (and reacts to a live change). Weak phones (`navigator.hardwareConcurrency < 4` or `navigator.deviceMemory < 4` when known): still mist field, effects kept (LEDGER `Mobile:`). No preloader, no pop-up on load, no scroll-jacking, no fade-up on every section.
6. **Accessibility WCAG AA:** one H1 per page, no skipped heading levels, skip link first, visible focus `outline: 2px solid currentColor; outline-offset: var(--focus-offset)`, no `role="menu"`, dialogs trap and return focus.
7. **Images:** through `Print`/`img()` (T05) only: box ≤ the row's `max_css_width`, `sizes` = the box, `<picture>` AVIF/WebP/JPG from the row's `files`, `width`/`height` set, first-screen image eager (+`fetchpriority="high"` for the LCP image), others lazy. Only rows with `status: "produced"`.
8. **Markers** (policy/components.md): `data-kit` on kit roots, `data-site-studio-component` on shared parts, `data-site-studio-logo`, `data-site-studio-embed`, `data-site-studio-consent`, `data-consent="accept|reject"`, `data-effect="pan|reveal|kinetic"`, `data-door`, `data-satellite`, home `data-beat` / `data-withheld` / `data-wow`.

10. **Implementer briefs** carry: caveman/lean-build, verify-and-stop, frontend-design (principles), web-typography#build, mobile-native, responsive-design (layout tasks), fixing-motion-performance (motion tasks), accessibility-compliance (interactive), navigation-menu (T08), scroll-experience (T10, T11, T14), policy/components.md for the component, DESIGN "Visual language" card and "Attention score" for home tasks.
